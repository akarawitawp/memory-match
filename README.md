# Memory Match V2 — Offline

เปิด `index.html` ด้วย Chrome ได้ทันที ไม่ต้อง Compile, ไม่ต้องติดตั้ง Node.js, ไม่ต้องใช้อินเทอร์เน็ต

- โหมดไอคอนผลไม้/รถ และโหมดภาษาจีน HSK 1 (150 คำ)
- เลือก 8 / 10 / 20 คู่ และผู้เล่น 1–4 คน ผลัดกันเล่นเครื่องเดียว
- จับคู่ถูกได้คะแนนและเล่นต่อ จับคู่ผิดเปลี่ยนตา
- ตั้งเวลา 5 / 10 / 20 นาที
- เล่นชุดเดิมสลับตำแหน่ง หรือสุ่มชุดใหม่
- เปิดคำศัพท์จีนหนึ่งใบแสดงตัวจีนใหญ่ พินอินและอังกฤษตัวเล็ก
- ข้อมูลทั้งหมดอยู่ในเครื่อง ไม่ส่งไปเซิร์ฟเวอร์

ไฟล์: `index.html` = หน้าตา, `script.js` = กติกา, `hsk1.js` = คำศัพท์

หมายเหตุ: เกมจบเมื่อจับคู่ครบหรือหมดเวลา ถ้าคะแนนสูงสุดเท่ากันถือว่าเสมอ

## เสียงอ่านภาษาจีน
เปิดโหมด HSK แล้วติ๊ก อ่านคำศัพท์จีนอัตโนมัติ เมื่อเปิดการ์ดจะมีเสียง Mandarin และกดปุ่ม ฟังคำล่าสุดอีกครั้ง เพื่อฟังซ้ำได้ เสียงใช้ Web Speech API ของ Chrome ขึ้นกับเสียงภาษาจีนที่ติดตั้งในระบบ อาจต้องเชื่อมต่ออินเทอร์เน็ตสำหรับบางเสียง
